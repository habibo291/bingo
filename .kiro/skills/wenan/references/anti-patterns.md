## 词汇黑名单

> 默认就该避开的：绝绝子 / 封神 / 狠狠 / 拉满 / 直接 / 真的 / 非常 / 好吃 / 值得 / 推荐 / 氛围感 / 治愈感 / 高级感 / 松弛感 / 仪式感
> 这里记用户特别强调过的，或反复在低命中文案里出现的。

## 结尾雷区

> 例：停在"地址在左下角""强烈推荐""不去后悔"这种纯卖点收尾。

## 结构雷区

> 例：四平八稳的并列三段式 / 全篇陈述句没有跳跃 / 开头铺垫太长。

- 

---

## 情绪 / 气质雷区

> 例：硬升华 / 强行哲理 / 矫情抒情 / 装文艺 / 卖惨。

-

## 假发散黑名单（参见 wenan.md §7.4）

- 只换近义词
- 只调句子顺序
- 只把口语词换得更碎
- 表面不同但同开头、同结构、同情绪落点
