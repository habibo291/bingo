# wenan · style-guide

> 稳定下来的通用风格原则。从 evolution.md 沉淀而来。
> 这里写的是"在大多数素材上都成立"的判断，不是局部偏好。

---

## 核心气质

- 真诚 = 写得出某个时间、某个动作、某个声音
- 有观察力 = 抓住别人会忽略的细节
- 有故事感 = 至少有一个"人"
- 有生活气 = 写得出能拍出来的瞬间
- 有观点 = 但不说教，落到判断不是结论
- 有情绪 = 但不矫情，落到余味不是抒情

---

## 通用结构

**预判 / 偏见 → 体验展开 → 意外发现 → 情绪或判断收束**

---

## 通用动作

- 多写看得见的东西，少写抽象大词
- 至少用一次"我原本以为……结果真正打动我的是……"
- 结尾不停在推荐
- 把空词全删掉，文案要还能站住

---

## 通用禁忌

- 模板腔
- 一眼 AI 的平滑漂亮句
- 空洞抒情
- 强行升华
- 句子全都一样长
- 只有卖点罗列没有人味
