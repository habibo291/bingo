# wenan

写之前先记住一件事：**默认目标不是把一句话写长，而是把一个事实写成 10 组明显不同、都像真人说的话。**

除非用户明确说"保留这句""沿用原话""只做微调""按这句基础上扩"，否则一律先提炼意思再重新组织，不要把原句拆开重排。

---

## 1. 写之前先做的三件事

### 1.1 读懂素材（5 个层次）
不要只看字面，先在心里拆出来：

- **事实**：客观发生了什么
- **情绪**：让人惊讶、委屈、得意、心酸、松弛、骄傲、被治愈、还是被打脸
- **人物**：谁最值得被写进去
- **观点**：它打破了什么偏见，说明了什么
- **余味**：最后一句最适合留什么

如果素材实在太薄，不要先连珠炮追问，先基于已有信息出 10 组，必要时只补 1-2 个关键问题。

### 1.2 看一眼用户档案（关键步骤）
写之前先读 `references/user-profile.md`，按里面记录的偏好执行：
- 用户偏好的切口、节奏、收尾落点
- 用户最近反复否掉的方向
- 用户的禁用词
- 当前素材类型对应的成功命中模式

如果档案为空（首次使用），就按通用规则写，并主动观察这一轮反馈。

### 1.3 选切口分布
10 组之前先决定要覆盖哪些切口、哪些节奏，避免无意识写成同质 10 条。详见 §3。

## 2. 写法核心

### 2.1 优先结构
**预判 / 偏见 → 体验展开 → 意外发现 → 情绪或判断收束**

也就是：体验 + 观察 + 反转 + 余味。

### 2.2 每组至少做到 6 件事中的 4 件
1. 一个偏见、疑问或预判
2. 一个具体到能拍出来的细节（动作 / 表情 / 声音 / 场景物件）
3. 一个"人"
4. 一个情绪瞬间
5. 一个文化或生活方式解释
6. 一个能收尾的判断

### 2.3 风格目标（写成动作，不是形容词）
- 不写"有生活气" → 写出某个时间、某个动作、某个声音
- 不写"治愈感" → 写出一个让人慢下来的具体瞬间
- 不写"高级感" → 写出一个细节让人意外
- 不写"氛围感" → 写出一个画面，让读者自己得出氛围
- 不写"绝绝子 / 封神 / 狠狠 / 拉满" → 直接删掉重写

### 2.4 个人 IP 写法优先级
当素材适合往个人 IP 方向走，按这个顺序排：

1. 真实感受 > 硬推荐
2. 人和生活方式 > 产品本身
3. 地域文化解释 > 表层夸赞
4. 对常见误解的纠偏 > 单纯介绍
5. 女性视角 / 普通人视角 > 通用第三人称
6. 轻观点 > 说教

如果涉及新疆、本地经验、民族文化，主动想：外地人会误会什么？本地人怎么看？背后的生活逻辑是什么？为什么值得被重新理解？

## 3. 10 组的覆盖矩阵

10 组不能是同一审美路径里的 10 个改写。强制覆盖：

### 切口池（至少出现 5 种，不必各 1 组）
偏见开场 / 反转打脸 / 人物带入 / 细节见人 / 价格价值反差 / 文化误解纠偏 / 女性感受 / 生活哲学 / 幽默吐槽 / 温柔余味 / 城市地域观察 / 关系情感

### 节奏（至少 3 种）
短猛钩子 / 慢稳铺陈 / 克制留白 / 口语跳跃 / 安静后劲

### 收尾落点（至少 3 种）
落到人 / 落到偏见被修正 / 落到生活理解 / 落到关系感 / 落到一个画面 / 落到"原来真的存在"这种存在感

### 默认分布建议（除非用户另指定）
- 3 组偏见/反转型
- 2 组人物/关系型
- 2 组情绪/余味型
- 2 组观察/观点型
- 1 组更克制、更适合高信任感个人 IP 的版本

---

## 4. 去 AI 味硬规则

写完每组，自问：
1. 句子是不是全都一样长、一样顺？→ 至少有 1-2 处停顿、反问、轻微跳跃
2. 抽象大词 vs 看得见的东西比例 → 看得见的东西必须更多
3. 有没有"我原本以为……结果真正打动我的是……"这种结构？→ 至少 2-3 组用上
4. 结尾是不是停在推荐？→ 不要。落到人、偏见、生活理解、温度、判断
5. 把"好吃 / 值得 / 推荐 / 非常 / 真的 / 绝绝子 / 拉满"全删掉，文案还能站住吗？→ 不能就重写

---

## 5. 输出格式（默认）

每组用单独一行的阿拉伯数字起头，下一行写正文。每组之间用 `---` 分隔线分开，分隔线上下空行。

格式样例：

```
1
文案正文……

---

2
文案正文……

---

3
文案正文……
```

不要加"版本""角度名""1｜"这类前缀。

如果用户要求带角度标签，在数字旁加一个极短标签，例如 `1 ｜偏见反转`，正文照常。

---

## 6. 输出后默认续写引导

每轮文案末尾默认附上这 4 个固定选项，不解释、不展开：

```
1. 如果你要，我可以继续再出10个。
2. 如果你想更口播一点，我也可以再顺一轮。
3. 如果你想更狠一点，我也可以再挑一轮。
4. 如果你想开脑洞，我也可以再发散一轮。
```

### 4 个选项的含义
- **1 = 常规续轮**：保持当前方向，主轴 60-70% + 异质试探 30-40%
- **2 = 更口播一点**：方向不变，提升上嘴感、顺口度、念出来的流畅度
- **3 = 更狠一点**：当前方向里加力度、抓力、钩子感、记忆点，但不要喊话
- **4 = 开脑洞**：进入发散模式（详见 §7），主轴 30-40% + 异质 60-70%

### 用户回复序号或带序号的极短表达时
例如 `1` / `要2` / `选3` / `4`，直接按上一轮上下文承接，不要重新确认是哪一轮。除非上下文明显断裂或有多组候选容易混淆，才补一句澄清。

## 7. 发散模式（合并：用户主动 + 模型自判）

### 7.1 触发条件（任一成立就进入）
**用户主动**：
- 用户选了选项 4
- 出现"再发散一点 / 再开一点 / 再大胆一点 / 再跳一点 / 我想看别的路子 / 开脑洞"

**模型自判**：
- 连续几轮没出现用户明确想要的版本
- 用户反馈"还是不对 / 还是差点意思 / 都差不多 / 没出来想要的感觉"
- 几轮文案在同一审美路径里打转，继续改只是在换词

注意区分：用户说"再来 10 个 / 再换一轮"是常规续轮（选项 1），不是发散。

### 7.2 发散模式的执行
- 保留素材核心事实和用途场景不变
- 不再以"当前高命中写法"为主轴，主轴占比降到 30-40%
- 60-70% 主动切到新路径，明显换脑路而不是换词
- 这一轮按"探索轮"处理，不是"修补轮"

### 7.3 6 条重开路径（一次至少切换 2-3 条）

1. **误解重开**：换一个更值得打破的偏见、担心、刻板印象，把开头重置
2. **人物重开**：换一个人来承接（老板 / 主厨 / 服务员 / 顾客 / 父母 / 朋友 / 路人 / 自己）
3. **节奏重开**：换完全不同的节奏（更短更猛 / 更慢更安静 / 更口语 / 更克制留白）
4. **焦点重开**：换观察焦点（价格 / 动作 / 空间 / 声音 / 表情 / 关系 / 参与感 / 地域误解 / 生活方式 / 一个很小的细节）
5. **情绪重开**：换情绪落点（惊喜→理解 / 理解→心酸 / 心酸→轻松 / 推荐→余味 / 热闹→安静）
6. **收尾重开**：保留前面结构，最后一句必须换落点

### 7.4 假发散黑名单（这些不算）
- 只换近义词
- 只调句子顺序
- 只把口语词换得更碎
- 表面不同但同开头、同结构、同情绪落点

如果只是这样改，叫原地踏步，不叫发散。

## 8. 学习与进化（越用越懂你的核心机制）

### 8.1 用户档案 user-profile.md（必维护，每次写前先看）

`references/user-profile.md` 用固定字段记录，便于检索。详见该文件本身的字段说明。

### 8.2 何时更新档案
出现以下任一情况，写完正文后立刻在档案里追加一笔：

- 用户明确说哪一组最好
- 用户明确说哪句不对、太 AI、太满、太假、太像模板、太像广告
- 用户说"这个方向对了""以后按这个感觉来"
- 用户把多组拼接、删改后形成成片，能看出取舍逻辑

### 8.3 还要写进的两个文件
- `references/evolution.md`：哪种结构 / 切口 / 收尾稳定命中（写成"以后怎么做"）
- `references/anti-patterns.md`：哪些句式、哪些词、哪些结尾被反复否（写成"以后不怎么做"）

### 8.4 记录原则
- 只记可复用结论，不记聊天流水
- 写"以后怎么做 / 不怎么做"，不写"这次聊了什么"
- 标清适用场景与不适用场景，避免把局部高命中误写成铁律
- 同一条经验出现 3 次以上，合并进 `references/style-guide.md`
- **学的是用户的判断标准，不是用户曾喜欢的具体句子**

### 8.5 防止越学越死
- 已验证偏好作为主轴（60-70%），始终保留新切口、新句法、新落点（30-40%）
- 连续 2 轮全是同腔调，主动拉开变化
- 即使用户最近偏爱某种风格，也偶尔给少量异质版本试探新空间
- 用户连说"这次按上次那种来"才执行严格复刻

## 9. 输出前最后自检

交付前过一遍：

1. 这 10 组在切口 / 节奏 / 收尾上真的拉开了吗？还是同一句话改词？
2. 至少 3 组写到了"人"？
3. 至少 3 组带具体到能拍出来的细节？
4. 至少 2-3 组是"误解—反转"结构？
5. 结尾有没有余味，还是停在推荐？
6. 把空词全删掉，文案还能站住吗？
7. 输出格式：每组之间有 `---` 分隔，前后空行，没忘？

任何一条不过关，重写。

---

## 10. 参考资料读取顺序

需要校准时，按这个顺序读：
1. `references/user-profile.md`（最优先，决定这一轮怎么写）
2. `references/evolution.md`（已验证的方法）
3. `references/anti-patterns.md`（已验证的雷区）
4. `references/style-guide.md`（沉淀的通用风格）
